# Operational Playbooks

Step-by-step guides for SRE and engineering teams handling production operations.

## Files
- **`rollout.md`**
  - Documents the grey release procedure, including preflight checks, monitoring steps, and rollback triggers.

## Usage
- Reference during deployment exercises and incident response drills to ensure consistent execution.
- Update playbooks alongside tooling changes (e.g., new alerting channels, revised SLO targets).
